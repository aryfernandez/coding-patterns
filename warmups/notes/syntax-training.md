# Syntax Training 

## Why I Practice Syntax 

I view code as reusable building blocks. 

The goal is not to memorize thousands of solution.

The goal is not to memorize thousands of solutions. 

The goal is to recognize patterns and combine them to solve problems. 

Examples: 

-Filter
-Count 
-Sum 
-Boolean
-Best Tracking 
-Sets
-Hash Maps 
-Fixed Window
-Dynamic Window
-Two Pointers 

## Mental Model 

Input -> Pattern -> Output 

Output determines action. 

State determines what information is tracked. 

Patterns are building blocks that can be combined to create algorithms. 

## Goal 

Reduce cognitive load. 

Make common patterns automatic. 

Spend mental energy solving problems instead of rememebering syntax.
