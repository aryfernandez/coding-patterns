### Early Return 

Not every problem requires additional processing. 

Mental Model:

Find answer. 

Stop. 

Go home. 

Examples:

- Duplicate found
- Target found
- Negative found
- Valid pair found

### Pattern Recognition 

Before coding:

Ask:

"What pattern is this?"

Examples:

- Consecutive -> Sliding Window
- Longest -> Best Tracking
- Count -> Accumulator
- Exists? -> Boolean
- Duplicate? -> Set
- Count Each? -> Frequency Map
- Sorted Array? -> Two Pointers

### Sets

A Set remembers what has already been seen.

Question:

"Have I seen this before?"

If yes:

Early Return.

## Biggest Realizations

Programming is becoming about recognizing patterns. 

The goal: "Identify the pattern and assemble the correct building blocks."

Examples of building blocks:

- Filter
- Count
- Sum
- Boolean
- Best Tracking
- Sets
- Hash Maps
- Sliding Window
- Two Pointers
- Early Return

## Things That Clicked 

State = information currently being tracked. 

Invariant = something that stays true, 

Optimization = reducing unnecessary work.

A good solution often removes work rather than adding more work.
